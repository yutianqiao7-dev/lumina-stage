# ルミナステージ(LUMINA STAGE)

好きなVRMキャラクターが、曲に合わせて自動で踊る **3Dライブビューアー** です。
ASCII.jp の記事(百夜ステージ)と同じ種類のアプリを、**完全無料**(ブラウザだけで動き、サーバー代も有料サービスも不要)で作りました。

## できること

| 機能 | 内容 |
|---|---|
| 曲の自動解析 | MP3などを読み込むと、テンポ・拍・小節の頭・曲の構成(イントロ/Aメロ/Bメロ/サビ/間奏/アウトロ)・盛り上がり(4段階)を自動で解析 |
| 振り付けの自動作成 | 36種類の短いムーブ(2〜8拍)のデータベースから、盛り上がりとスタイル(かわいい/クール/パワフル/しっとり)に合わせて並べる。同じ種類のセクション(サビなど)は同じ振り付けを繰り返し、左右反転も入れて「ダンスらしく」する |
| 自然な動き | 腕と脚は2ボーンIKで計算、足は床に固定(足すべりなし)。ムーブのつなぎ目はなめらかにブレンド |
| キャラ | 8人から選べる(タイトル画面か ☰ →「キャラ」): pixiv 公式サンプルVRM(標準)、VRoid Studio の CC0 サンプル7体(千駄ヶ谷 渋・渋ダーク・ビビ・ヴィータ・ヴィクトリア・千駄ヶ谷 篠・桜田 史利矢)。ほかに自分のVRM(0.x・1.0)、ロボット風の内蔵キャラ「ルミナ」。選んだキャラは次回も使われる。表情(笑顔・ウインク)、まばたき、歌声に合わせた口パク、カメラ目線、髪やスカートの揺れ |
| バックダンサー | メインのキャラを色違い(髪・服の色だけ変えて肌は残す)にして2人/4人。左右で鏡うつし |
| 照明・演出 | ムービングライト22台、レーザー、LEDの床、LEDの大型スクリーン(5種類の映像+ライブカメラ映像)、サイドスクリーン、ストロボ、サビ前の暗転、火花、紙吹雪、床のスモーク、観客約1700人とペンライト(曲ごとのテーマ色) |
| 自動カメラ | 14種類のショット(引き・全身・顔アップ・回り込み・クレーン・客席から・背中から・真上・手持ちなど)を、盛り上がりに合わせて小節の頭でカット |
| 立体歌詞 | 1文字ずつ3D空間に配置して、飛び込み・カラオケ式の色変わり・舞い上がりで表示。奥に残像レイヤーも重ねる。字幕表示も可 |
| 録画 | ライブを最初から最後まで動画(WebM)で保存 |
| デモ曲 | このアプリのために作ったオリジナル曲3曲(その場で作曲・演奏して生成。著作権の心配なし) |

## 使い方(自分のパソコンで動かす)

いちばん簡単なのは **`起動.bat` をダブルクリック** です(初回は準備に少し時間がかかります)。

手動で動かす場合:

1. このフォルダで次を実行(初回だけ `npm install` も必要)
   ```powershell
   npm install
   ```
   ```powershell
   npm run dev
   ```
2. ブラウザで http://127.0.0.1:5173 を開く
3. 「ライブをはじめる」を押す

VRM・曲・歌詞は、画面にドラッグ＆ドロップするか、右上の ☰ パネルから読み込めます。

### 歌詞ファイル
- **LRC形式**(`[00:12.34]歌詞`、単語ごとの `<00:12.80>` にも対応)なら時刻どおりに表示
- **ふつうのテキスト**なら、解析した曲の構成に合わせて2小節ずつ自動で割りふり

### キー操作
スペース=再生/停止、←→=5秒移動、N/P=次/前の曲、C=カメラ切替、1〜9=ショット選択、R=振り付けを作り直す、H=画面の表示を隠す、F=全画面、?=操作方法

## 無料で公開する(記事と同じ itch.io など)

```powershell
npm run build
```

`dist` フォルダの中身が、そのまま公開できる完成品です(相対パスで作ってあるので、どこに置いても動きます)。

- **itch.io**: `dist` の中身をZIPにして、新規プロジェクトの「Kind of project: HTML」でアップロード →「This file will be played in the browser」にチェック
- **GitHub Pages / Netlify / Cloudflare Pages**: `dist` をそのまま公開

## 構成(src)

| ファイル | 役割 |
|---|---|
| `audio/analyze.js` | 曲の解析(FFT・オンセット・テンポ推定・動的計画法による拍トラッキング・小節頭・自己類似による構成分け・盛り上がり)と歌詞の読み込み |
| `audio/synth.js`, `audio/songs.js` | デモ曲の自動作曲・演奏(区間ごとに並列レンダリング) |
| `audio/engine.js` | 再生・シーク・リアルタイム周波数解析 |
| `dance/moves.js` | ムーブのデータベース(記事の「句の庫」に相当) |
| `dance/composer.js` | 振り付けの自動作成(記事の「Dance Composer」に相当) |
| `dance/rig.js`, `dance/pose.js` | ポーズ→ボーン回転(IK) |
| `dance/dancer.js`, `dance/mannequin.js` | VRM読み込み・色違い・表情 / 内蔵キャラ |
| `stage/*` | 会場・照明・LED・観客・特効 |
| `camera/director.js` | 自動カメラ |
| `lyrics/lyrics3d.js` | 立体歌詞 |
| `post/post.js` | ブルーム・色収差などの仕上げ |

## メモ
- 読み込んだVRM・曲・歌詞はブラウザの中だけで使われ、どこにも送信されません。
- 重いときは自動で画質を下げます(☰ →「画質」で手動でも変更可)。
- 使うVRMや曲を公開する場合は、それぞれの利用条件(VRMのライセンス、Sunoなどの規約)を確認してください。

## 同梱キャラのライセンス
- `public/models/my_model.vrm`(ため): ユーザー自作の VRoid モデル。再配布・改変・商用利用を許可して書き出し済み
- `public/models/default.vrm`: pixiv Inc. の VRM 1.0 サンプル(VRM Public License 1.0。再配布・改変・商用OK、クレジット不要)
- `public/models/vroid_*.vrm`, `shino.vrm`, `sakurada.vrm`: VRoid Studio 旧ベータ版のサンプルモデル。pixiv 公式ヘルプで **CC0**(著作権放棄)と明記されています → https://vroid.pixiv.help/hc/ja/articles/4402614652569
