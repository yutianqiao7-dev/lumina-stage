曲リスト

MP3などを読み込むと、テンポ・拍・曲の構成(Aメロ/サビなど)・盛り上がりを自動で解析して、振り付けと演出を作ります。Sunoで作った曲もそのまま使えます。

キャラをえらぶ

標準キャラ

VRoid Studio・きゃらくる などで作った VRM(0.x / 1.0)が使えます。用意したキャラは pixiv 公式のサンプル(VRoid Studio の CC0 モデルなど)で、再配布・改変・商用利用OK・クレジット不要です。読み込んだファイルはこのパソコンの中だけで使われ、どこにも送信されません。

バックダンサー

「メインの色違い」は髪や服の色だけを変えます(肌の色は残します)。好きなキャラを1人ずつ選ぶこともできます。

ダンスの種類

本物のダンス: プロダンサーのモーションキャプチャー(AIST++、9ジャンル)を曲のテンポと構成に合わせてつなぎます。

歌詞の表示

LRC形式([00:12.34]歌詞)なら時刻どおりに表示します。ふつうのテキストなら、解析した曲の構成に合わせて2小節ずつ自動で割りふります。

🎮 ステージチャレンジ

いま選んでいる曲で遊びます。画面に出る的へ飛んでくるマークが、的に重なった瞬間にボタンを押してください。曲の拍と構成から譜面を自動で作るので、読み込んだ曲でも遊べます。

長押しマーク(外側に輪があるもの)は、輪が一周するまで押し続けます。ゲームパッドやスマホのタッチボタンでも遊べます。最後のサビは得点2倍のフィーバータイム!

🎙 ほかのタブの音を録音

  1. 先に、別のタブで Suno などの曲のページを開いておく(まだ再生しない)
  2. 下の「録音を始める」→ 出てきた画面で 「Chrome タブ」 からそのタブを選び、「タブの音声も共有する」をオン にして「共有」
  3. そのタブで曲を 最初から 再生する(このアプリの音は止めておきます)
  4. 曲が終わって4秒静かになると、自動で止まって読み込みます

パソコンの Chrome / Edge で使えます。録音は自分で楽しむためだけに使ってください(Suno の無料プランの曲などは、公開する作品に入れないでください)。
